📘 MANUAL COMPLETO DO SISTEMA

⚙️ 1. Banco de Dados de Produtos
🧠 O que é?
O Banco de Dados funciona como a memória do aplicativo.
Quando um produto é cadastrado uma única vez, o sistema preenche automaticamente diversas informações nos próximos lançamentos.
📋 Campos do Cadastro

🔤 Nome do Produto
Identificação principal da mercadoria.
Exemplo: Coca-Cola Lata, Fanta Laranja, Guaraná 2L.

📦 Volume
Tamanho da embalagem.
Exemplos: 269ml, 350ml, 600ml, 2L.

🏷️ Tipo
Define como o produto é comercializado.
• Unidade
• Caixa/Fardo

📊 Quantidade Interna
Quantidade de unidades dentro do fardo ou caixa.
Exemplo: Fardo com 12 unidades → informar 12.

🚨 Margem de Alerta
Quantos dias antes do vencimento o sistema destacará o item em vermelho.
Padrão recomendado: 7 dias.
🔍 Editando um Produto

1️⃣ Utilize a barra de pesquisa.
2️⃣ Digite parte do nome do produto.
3️⃣ Clique na linha encontrada.
4️⃣ Os dados serão carregados automaticamente.
5️⃣ O botão mudará para 📝 Atualizar Produto.
6️⃣ Faça as alterações e salve.
💡 Exemplo

Produto: Fanta Laranja
📦 Tipo: Fardo
📊 Quantidade Interna: 6
🚨 Alerta: 10 dias

Depois disso, ao digitar apenas "Fanta", o sistema preencherá automaticamente as informações cadastradas.

💾 4. Sincronização na Nuvem e Backup
☁️ Onde os dados ficam salvos?
Ao entrar com uma conta Google, todos os dados (Banco de Produtos, Lançamentos, Pesos e Perfil) são salvos automaticamente no Firebase — a nuvem do sistema.

📱 Abre em outro celular? Basta fazer login com a mesma conta e tudo já estará lá.
📡 Cada ação exibe a mensagem "☁️ Salvo na nuvem!" confirmando que o dado foi para o servidor.
🔒 Dados de contas diferentes nunca se misturam — cada usuário tem seu espaço exclusivo.
🔌 Sem internet ou sem login Google?
O sistema salva os dados localmente no aparelho e funciona normalmente.
Assim que a internet voltar ou o login for feito, os dados são migrados para a nuvem automaticamente.
🚪 Sair da conta com segurança
Ao clicar em SAIR DA CONTA, o sistema aguarda a sincronização final antes de deslogar, garantindo que nenhum dado seja perdido.
🛡️ Backup Manual (complementar)
Mesmo com a nuvem ativa, você pode exportar um backup JSON ou CSV a qualquer momento como cópia de segurança extra.

1️⃣ Clique em Exportar Backup
2️⃣ Salve o arquivo no celular, WhatsApp ou e-mail
3️⃣ Para restaurar, clique em Importar Backup e selecione o arquivo
🔢 5. Lançamento com Unidade Avulsa
🎯 Para que serve?
Permite registrar uma quantidade em unidades individuais quando há quebra de fardo ou caixa — por exemplo, quando um fardo de 12 unidades está incompleto.
✅ Como usar?

1️⃣ Selecione o produto normalmente.
2️⃣ Marque a opção "🔢 Lançar como Unidade Avulsa" abaixo do botão Adicionar.
3️⃣ Digite a quantidade em unidades individuais.
4️⃣ Informe a data de vencimento e clique em ➕ Adicionar à Lista.

O lançamento será registrado como "unid (avulso)", diferenciando da quantidade normal do produto.
O cadastro original no banco de dados não é alterado — apenas aquele lançamento específico fica marcado como avulso.
