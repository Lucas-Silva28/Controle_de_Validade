# Controle_de_Validade
Controle de Validade: Sistema para gestão de estoque e prazos. Com alertas visuais (Crítico/Alerta), gerencia fardos e unidades via mobile. Gera relatórios PDF e compartilha via WhatsApp. Ferramenta essencial para evitar perdas financeiras e organizar o inventário com precisão técnica e agilidade, tudo funcionando offline e direto do celular.
